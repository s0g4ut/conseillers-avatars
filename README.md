# Conseillers — avatars

Portraits illustrés des conseillers fictifs de l'équipe (personnages inventés).
Un fichier par conseiller dans `avatars/`, nommé d'après son prénom actuel, en minuscules et sans accent (ex. `daphne.webp`, `manu.webp`).
Les anciens fichiers au premier prénom (ex. `diane.webp`, `scott.webp`) sont conservés le temps de la transition.
